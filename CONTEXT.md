# Siterm

Siterm is a personal publishing space expressed as an interactive, continuous terminal experience.

## Language

**Terminal session**:
The single continuous context in which visitors express intent through commands and receive the site's content as textual responses.
_Avoid_: App shell, dashboard, terminal window, terminal-themed website

**Terminal-native interface**:
An interface whose information structure, interaction, and output grammar follow terminal conventions while retaining modern readability.
_Avoid_: Vintage machine simulation, retro skin, sci-fi dashboard

**Transcript**:
The chronological record of visitor commands and the textual responses emitted by the site during a terminal session.
_Avoid_: Page view, content panel, output card

**Terminal profile**:
A named, coherent foreground-and-background color configuration for the terminal session.
_Avoid_: Theme skin, palette card, color picker

**Status line**:
The single persistent summary row at the bottom of the terminal session, separate from the transcript.
_Avoid_: Footer, toolbar, application status bar

**Boot sequence**:
The opening ASCII presentation that establishes Siterm's identity before yielding to the first prompt, without imitating hardware startup.
_Avoid_: Navigation menu, BIOS simulation, loading screen

**Character vocabulary**:
The consistent set of ASCII line, density, and framing patterns used to give terminal responses a shared visual voice.
_Avoid_: Unrelated FIGlet styles, decorative emoji, arbitrary text art
