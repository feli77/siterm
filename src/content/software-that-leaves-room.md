There is a kind of software that seems to tighten around you as you use it. Every path is anticipated, every choice is framed, and every quiet moment becomes a notification. It is efficient in the narrowest sense and exhausting in every other one.

## Tools should create capacity

A good tool does not merely complete a task. It enlarges the space in which its user can think. It exposes enough of its model to be understood, then gets out of the way. The terminal remains a useful example: small vocabulary, visible state, composable results.

> The interface is finished when the user can form an intention the designer did not predict.

This does not mean every interface should become a command line. It means our interfaces should respect the people operating them. Defaults can guide without becoming walls. Automation can assist without concealing cause and effect.

## Three practical tests

- Can a curious person discover how the system behaves?
- Can an experienced person move faster without fighting the defaults?
- Can someone leave without their work being held hostage?

Software that passes these tests feels unusually calm. It leaves room for judgment, and that room is where people do their best work.
